# Catálogo de funcionalidades

O catálogo declara somente os slugs estáticos das funcionalidades Core com implementação prevista.
Ele não contém IDs de banco, permissões, ações, rotas, componentes React ou estado de navegação.

O slug identifica o binding do Web e a funcionalidade persistida. A autorização continua sendo
determinada pela sessão e pela API no contexto de usuário, cliente e perfil.
